# ControlLab Web — Pacote de referência v1.0

Este pacote reúne o documento diretor convergido para desenvolvimento por oito frentes produtoras (F1-F8) e uma frente independente de integração e garantia da qualidade (F9).

- `ControlLab_Web_Documento_Diretor_v1.0.pdf`: versão para distribuição e leitura.
- `ControlLab_Web_Documento_Diretor_v1.0.docx`: versão editável para novas iterações.
- `ControlLab_Web_Documento_Diretor_v1.0.md`: fonte textual para agentes, com links para figuras.
- `controllab_v1_assets/arquitetura_v1.png` e `dependencias_v1.png`: diagramas.

**Importante:** a v1.0 é uma baseline de requisitos, não uma evidência de implementação concluída. A compatibilidade SDP/Clarabel/Pyodide e a exportação PathView são condicionadas aos gates previstos no documento.

Recomenda-se que F9 congele inicialmente os contratos, ownership e fixtures antes de solicitar implementações concorrentes. Os agentes não devem assumir que trechos JSON com marcadores textuais de exemplo representam resultados científicos reais.

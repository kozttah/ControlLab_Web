Modelo matemático e teoria fuzzy

Material didático do Laboratório Virtual de Controle Fuzzy. Edite este arquivo para adequá-lo às suas aulas.

1. Planta: modelo cinemático de robô móvel

O modelo utilizado é o modelo cinemático de uniciclo. O vetor de estados é x = [x, y, θ]ᵀ, e os comandos são a velocidade linear v e a velocidade angular ω.

\[\dot{x}=v\cos\theta,\qquad \dot{y}=v\sin\theta,\qquad \dot{\theta}=\omega.\]

O erro angular é a diferença entre a direção do vetor que liga o robô à referência e a orientação do robô, normalizada para \([ -\pi,\pi ]\). O erro de posição é a distância euclidiana.

\[e_1=\operatorname{wrap}_{[-\pi,\pi]}\!\left(\operatorname{atan2}(y_r-y,x_r-x)-\theta\right),\qquad e_2=\sqrt{(x_r-x)^2+(y_r-y)^2}.\]

2. Estrutura do controlador Mamdani

O controlador possui duas entradas (EA e EP) e duas saídas (VA e VEL). Uma regra associa conjuntos fuzzy das entradas a conjuntos fuzzy das duas saídas.

\[R:\quad \text{SE } EA\text{ é }A_i\ \text{E }EP\text{ é }B_j\ \text{ENTÃO }VA\text{ é }C_k\ \text{E }VEL\text{ é }D_l.\]

As funções de pertinência disponíveis no laboratório são triangulares, trapezoidais e gaussianas.

Quando a fuzzificação não singleton é usada, a interface permite ajustar a meia-largura Δ da fuzzificação triangular, o desvio padrão σ da fuzzificação gaussiana e o número de amostras empregado na aproximação do Modus Ponens Generalizado.

\[\mu_G(z)=\exp\!\left[-\frac{1}{2}\left(\frac{z-c}{\sigma}\right)^2\right],\qquad \sigma>0.\]

3. Integração numérica

A simulação utiliza Runge–Kutta explícito de quarta ordem, com o comando mantido constante em cada passo.

\[x_{k+1}=x_k+\frac{h}{6}(k_1+2k_2+2k_3+k_4).\]

4. Atividade sugerida

A configuração fuzzy começa vazia. Defina os conjuntos de pertinência, atribua nomes linguísticos e construa a base de regras antes de executar o controlador fuzzy. A configuração pode ser salva e carregada em XML/FML.
